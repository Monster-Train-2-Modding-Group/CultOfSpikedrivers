支持的语言: [English](https://github.com/Monster-Train-2-Modding-Group/CultOfSpikedrivers/blob/main/README.md) | 简体中文

本模组将咩咩启示录联动事件的追随者替换为一代中的钉锤大队。

本模组是替换资产（音效、spine 动画、卡牌图片）的一个示例模组。

## 功能

* 将“追随者”的外观替换为一代“钉锤大队”的外观。
* 通过 .cfg 文件可以选择将卡牌效果替换为一代“钉锤大队”的效果。
  * **注意**：如果启用了该功能，该模组**不再是装扮类模组**，不应该在社区挑战或者每日挑战内使用本模组。

## 安装 / 使用方法

**强烈**建议使用一个模组管理器（Thunderstore Mod Manager、Gale Mod Manager或r2modman）来安装这个模组。如果手动安装，则需要同时安装[Trainworks Reloaded](https://github.com/Monster-Train-2-Modding-Group/Trainworks-Reloaded)。

安装之后，首先运行游戏一次，生成配置文件。

* 如果使用模组管理器安装，可以在 config editor 里编辑该文件。

* 如果手动安装，该文件正常会出现在游戏根目录的 BepInEx 文件夹内，一般该文件的位置在类似于 `C:\Program Files (x86)\Steam\steamapps\common\Monster Train 2\BepInEx\config\CultOfSpikedrivers.Plugin.cfg` 的地方。

>  [!警告]
> 
> 如果启用了“Enable Classic Spikedriver Colony”，则不应该在社区挑战或者每日挑战内使用本模组。
